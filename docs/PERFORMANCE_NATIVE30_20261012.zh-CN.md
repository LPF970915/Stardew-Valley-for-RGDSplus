# 原始分辨率、垂直同步与 30 帧目标（2026-10-12）

用户实机反馈：20261012-01 的低分辨率放大与取消客户端交换等待，虽然测得四十多帧，
但实际观看有抖动和掉帧。本轮以原画质、接近 30 帧及帧间隔为目标。

## 最终代码

- 正式入口默认 `SDV_WORLD_RENDER_SCALE=1`，SDL GL 交换间隔为 1。
  100% 世界缩放时，连续世界纹理为 1024×1536，双屏物理承载仍为 2048×768。
- `SDV_TARGET_FPS=30`：在 Game.DoDraw 前决定是否绘制，不修改 Game.Tick 的
  固定更新步长。实际更新仍为 16.6667 ms。绘制期间累积跳过绘制的 elapsed time，
  让 Draw 参数和 Game1.currentGameTime 引用读取一致；结束或异常时恢复更新用值。
  长帧后跳过过期绘制时点，不连发补偿帧。
- `SDV_WORLD_ALPHA_DISCARD=1`：仅为世界的标准 AlphaBlend SpriteBatch 使用
  AlphaTestEffect，保留相同投影、颜色、半透明和排序。原生 UI、自定义 effect、
  特殊混合及地图截图绕过此路径。
- `SDV_TREE_TRIM=1`：仅在原始分辨率、PointClamp、标准效果、静止、整数坐标、原生 4 倍精灵倍率的 48×96 树冠
  上，将完全零 RGBA 的空白边缘裁去。翻转时校正 origin。摇动或倒下的树保持原绘制。
  从实际纹理每 32 行建立一段范围，最多三段，面积减少不足 20% 则保持整张矩形。纹理缓存使用弱引用，
  返回标题清理；纹理读取失败时回退原绘制。未硬编码某季节的树冠轮廓。小数精灵倍率、其他 origin、额外变换和全局矩阵均回退；
  这是因为设备的 TextureTuckAmount 会使裁剪后的小数采样出现差异。
- 没有更改 CPU/GPU 频率策略、固件、分辨率设置或真实存档；没有启用 RGA。

## 测量方法与范围

全部实机测试保持静音；通过正式入口与隔离的 XDG_CONFIG_HOME 建立内存农场。
没有加载、保存真实农场。工具动作由游戏 API 触发，移动由 SMAPI 输入模拟。
这不等同于真人操作长时间真实存档。

证据目录：`build/performance-native30-20261012/`。`candidate-*` 使用正式候选 DLL，
没有 RenderScaleProbe 注入；`native-*` 是对照/原型。只比较同场景、同动作、冷/热状态
明确的样本，不能把静止场景与动作后不同的相机位置视为同等负载。

每段通常 30 秒。`-frames.csv` 测量真正绘制后的间隔，跳过绘制的 Tick 不算帧；
更新计时仍累积。`-methods.csv` 提供边界计时，边界互相包含，不能求和。
截图在计时停止后抓取。

另用 QA 原生库获取当前 SDL Wayland surface 的 `wp_presentation` 反馈，不增加
交换或像素读取。CSV 同时保留提交、呈现时间、输出、序列号、flags、discarded。
早期在 Game.EndDraw 前请求反馈，不能证明请求与缓冲提交一一对应；即便去重也不能直接当屏幕帧数。
`commit32-*` 起改为在 Wayland 实际附带 EGL 缓冲的 surface.commit 前请求反馈，
同时记录提交编号、总提交数和附带缓冲的提交数，用于核对覆盖范围。该采样仅存在于 QA 的 LD_PRELOAD 库中。
本设备反馈只报告一个输出，不能据此声称已独立测量上下两块屏幕。
时间戳来自 CLOCK_MONOTONIC，flags=7；刷新周期约 16.612 ms。
请求 SDL swap interval=2 后读取仍为 1，因此不能声称启用了硬件半刷新率同步。

## 对照结果

原分辨率、同步、不裁剪的重复砍树样本 `native-paced30-axe-warm`：
26.66 FPS，P95 41.02 ms，最大 56.22 ms。只启用透明像素效果为 28.50 FPS。
裁剪和透明效果合用的原型重复样本 `native-trim-alpha-v2-axe-warm`：
29.71 FPS，P95 36.31 ms，最大 44.07 ms。该段旧采样得到 29.57 个唯一反馈时间/秒；
因未对齐实际缓冲提交，仅作历史诊断记录，不据此判断物理显示帧率。

极密 930 格树木、相机位于中间且不挥工具的压力样本，原绘制约 18 FPS，
只裁剪树冠约 22.16 FPS。这比动作测试的相机位置更重，仍明显达不到 30。
早期 `native-trim30-*` 原型没有截获被内联的 float Draw 重载，不能作为有效裁剪结果；
`native-trim-v2-*` 改为截获实际 Vector2 Draw 重载，已生成裁剪范围记录。

## 首次动作仍未解决

候选首次混合割草样本最大 773.06 ms，其中该帧 JIT 统计增量 630.31 ms；
同进程重复样本最大 43.17 ms，峰值帧 JIT 为 0。
原型首次砍树最大 561.58 ms，JIT 增量 438.64 ms；重复最大 44.07 ms。
这些是带诊断补丁的实测，不能把所有 JIT 时间和正式无探针玩家体验简单等同，
但足以确认渲染优化未解决首用长帧。没有把广泛预编译或 R2R 的未通过方案放进发布包。

## 验证与回退

本地精确设备程序集 Harmony 安装、界面布局/触摸/天气/对话回归通过。
新增绘制节奏检查覆盖时间累计、过期时点和时钟重置；树冠检查覆盖边界像素、
零 alpha 非零 RGB、不重复混合及无需裁剪的矩形。发布/导入 7 项、音频恢复 9 项通过。
设备上的 6 组透明效果对照共比较 98,304 像素，通道最大差异为 0。
树冠进一步对比合成纹理与真实春季树纹理，包含翻转和半透明：32 组中，
1.5 倍精灵绘制出现 3596 个差异像素，1/2/4 倍为 0。最终仅启用原生 4 倍、
整数坐标、标准 origin、无额外变换的路径；该范围 8 组共 2,097,152 像素差异为 0。
这里的精灵倍率是引擎内部 Draw 参数，不是玩家设置中的世界缩放。
原失败记录为 `release-pixel-check.json`，完整细项为 `release-final-pixel-check.json`。

发布号 `20261012-02`。入口各开关可单独设为 0 关闭优化（分辨率开关仍保持 1）；
取消 30 帧限制使用 `SDV_TARGET_FPS=0`。更改后须退出重进。
旧版缩放实验记录保留在 `PERFORMANCE_RENDER_SCALE_20261012.zh-CN.md`，不代表当前默认设置。

## 提交点复核与最终取舍

为核查旧反馈的重复时间戳，QA 库改为拦截设备 Wayland 的公共
`wl_proxy_marshal_array_flags`，只在当前 SDL surface 附带非空缓冲的 commit 前
请求 presentation feedback。EGL 的 queue wrapper 通过协议对象 ID 匹配。
设备库反汇编确认旧式、可变参数 marshal 最终转到该数组入口。该库只用于测试，
不进入发布包，不增加交换、readback 或同步 roundtrip。

`commit32-axe-warm` 连续约 60 秒：

- 绘制 29.135 FPS，绘制间隔 P95 37.36 ms，最大 58.31 ms，超过 50 ms 共 2 帧。
- 1761 次缓冲提交收到 1760 次反馈，测量停止时尚有一个未回调；没有重复时间戳或 discarded。
- 反馈覆盖区间为 29.172 FPS，间隔 P50 33.223 ms、P95 49.834 ms、最大 49.941 ms。
- 间隔按刷新周期计：1577 次两刷新、147 次三刷新、35 次一刷新；完整秒内为 27–31 帧。

旧采样曾推算约 27 FPS，不能再据此断言额外丢失了两帧。提交点复核与绘制统计接近，
但一/三刷新间隔仍存在，不能承诺帧间隔完全均匀，也不能代表两个物理屏幕独立测量。
上述复核使用已安装的固定 32 行版本；下方 final32 样本对应最终归档 DLL。

固定 16 行重复砍树绘制约 28.87–29.15 FPS，固定 8 行为 26.47 FPS。
自适应最多三个矩形约 29.32 FPS，没有明显胜过固定三段，已从正式源码移除。
这些更细/自适应试验只有旧反馈采样，不能用其推算显示端胜负。
最终保留固定 32 行、最多三段方案，避免增加未经证实有收益的计算与绘制数量。
