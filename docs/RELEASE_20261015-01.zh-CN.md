# Stardew Valley for RGDSplus 20261015-01

RGDSplus 双屏适配包，不含 Stardew Valley 游戏本体。请先购买游戏，并用包内导入器从自己合法取得的 Windows Steam 主线版导入资源。

## 更新内容

- 加入双屏肖像 MOD 兼容处理，并在发布包私有 MOD 副本中生成缩小肖像；原始 MOD 与 Steam 资源保持不变。
- 修复双屏模式下原版对话显示和商店菜单尺寸适配；加载新游戏或存档时显示 SMAPI 加载阶段提示。
- 改进 MOD 列表、启用状态与依赖处理，并保留首次工具动作预热和退出诊断。
- 随包提供 ARM64 运行依赖及 Windows Steam 本地资源导入工具。

## 安装

下载本 Release 附件中的 `Stardew Valley for RGDSplus.zip`，将包内唯一的 `Ports/` 合并到第二张卡根目录。然后在 Windows 上运行 `steam-import/Import Steam Assets.cmd`，选择自己购买的 Stardew Valley 安装目录。完成后安全弹出内存卡，从 Ports 菜单启动游戏。

升级前备份 `savedata/` 和 `Mods/RGDSplus.VerticalWorld/` 用户配置。详细步骤、兼容范围和排错方式见 [发布包说明](../packaging/README.zh-CN.md)。
